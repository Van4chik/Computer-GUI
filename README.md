# Лабораторная работа №2 - Сигналы и слоты

## Задание
Разработать графическое приложение на PyQt5, демонстрирующее механизм сигналов и слотов. При изменении значения в одном из полей ввода должны автоматически пересчитываться значения в остальных полях.

## Описание программы
Программа написана на языке **Python** с использованием библиотеки **PyQt5**.
Приложение представляет собой графический конвертер валют с тремя полями ввода:

- **Доллар (USD)**;
- **Рубль (RUB)**;
- **Евро (EUR)**.

При изменении суммы в любом поле программа пересчитывает эквивалентные суммы в двух других валютах.
Для пересчёта используются заданные курсы валют относительно рубля. Эти значения являются константами.

## Используемые библиотеки
В программе используются компоненты PyQt5, такие как:

```python
from PyQt5.QtCore import *
from PyQt5.QtGui import *
from PyQt5.QtWidgets import *
```

Также используются стандартный модуль `sys` и три модуля проекта: `cl1`, `cl2` и `cl3`.

### Основные компоненты
- `QApplication` — создание приложения и запуск цикла обработки событий;
- `QMainWindow` — основное окно приложения;
- `QLineEdit` — поля для ввода сумм в разных валютах;
- `QFormLayout` — размещение подписей и полей ввода в виде формы;
- `QWidget` — контейнер для элементов интерфейса;
- `QDoubleValidator` — ограничение вводимых значений числовым форматом;
- `pyqtSignal(float)` — объявление сигнала, передающего числовое значение типа `float`.

## Интерфейс приложения
При запуске создаётся главное окно с заголовком **«ЛР №2 Сигналы-Слоты: Конвертер валют»**. В окне размещены три строки с подписями и полями ввода:

1. `Доллар (USD)`;
2. `Рубль (RUB)`;
3. `Евро (EUR)`.

Для полей ввода задаётся валидатор `QDoubleValidator`, который предназначен для ввода чисел в допустимом диапазоне. Значения пересчёта отображаются с точностью до четырёх знаков после запятой.

## Принцип работы конвертера
В программе заданы курсы валют относительно рубля:

```python
self.usd_to_rub = 80.5381
self.eur_to_rub = 90.2429
```

Пересчёт выполняется по формулам:
- из долларов в рубли: `RUB = USD × usd_to_rub`;
- из рублей в евро: `EUR = RUB / eur_to_rub`;
- из евро в рубли: `RUB = EUR × eur_to_rub`;
- из рублей в доллары: `USD = RUB / usd_to_rub`.

В качестве промежуточной валюты используется рубль. При изменении любого поля вычисляются значения для двух остальных валют.

### Изменение поля доллара
Поле доллара подключено к обработчику `usd_changed()` через сигнал `textChanged`:

```python
self.usd_edit.textChanged.connect(self.usd_changed)
```

Обработчик преобразует введённый текст в число, рассчитывает суммы в рублях и евро, а затем устанавливает полученные значения в соответствующие поля.

### Изменение поля рубля
Поле рубля подключено к обработчику `rub_changed()`:

```python
self.rub_edit.textChanged.connect(self.rub_changed)
```

При изменении значения в рублях программа вычисляет эквиваленты в долларах и евро.

### Изменение поля евро
Поле евро подключено к обработчику `eur_changed()`:

```python
self.eur_edit.textChanged.connect(self.eur_changed)
```

При изменении суммы в евро рассчитываются эквивалентные значения в рублях и долларах.

## Использование сигналов и слотов
Основная цель ЛР — показать взаимодействие сигналов и слотов в PyQt5.

Сигнал `textChanged` каждого `QLineEdit` срабатывает при изменении текста в соответствующем поле и вызывает связанный с ним метод пересчёта. Связь создаётся методом `connect()`.

Кроме сигналов полей ввода, приложение использует сигналы, объявленные в модулях `cl1`, `cl2` и `cl3`. В каждом из этих модулей создаётся класс-обёртка `QObject` с сигналом:

```python
mySignal = pyqtSignal(float)
```

В главном окне сигналы подключаются к слотам-обработчикам:

```python
self.myClsig.connect(self.on_rub_signal)
self.myDolsig.connect(self.on_dolar_signal)
self.myUsdsig.connect(self.on_usd_signal)
```

После пересчёта соответствующий сигнал отправляет актуальное значение с помощью `emit()`. Слоты `on_rub_signal()`, `on_dolar_signal()` и `on_usd_signal()` выводят в консоль сообщение о зафиксированном изменении валюты.

Для предотвращения бесконечного взаимного вызова обработчиков при программном обновлении соседних полей используется флаг `self.updating`. Перед установкой рассчитанных значений флаг включается, а после обновления выключается. Пока флаг активен, обработчики изменений полей сразу завершают работу.

## Структура программы
Проект состоит из главного модуля и трёх дополнительных модулей, в которых объявлены сигналы.

| Файл / элемент | Назначение |
|---|---|
| `main.py` | Создание окна, полей ввода, пересчёт валют и подключение сигналов |
| `cl1.py` | Объявление сигнала для изменения значения в рублях; содержит функцию `func()` для демонстрации инициализации данных |
| `cl2.py` | Объявление сигнала для изменения значения в евро |
| `cl3.py` | Объявление сигнала для изменения значения в долларах |
| `Some` | Класс главного окна приложения |
| `Data` | Класс для хранения списка данных, используемый функцией `cl1.func()` |

### Основные методы класса `Some`
| Метод | Назначение |
|---|---|
| `__init__()` | Создание окна, полей ввода, валидаторов, курсов и соединений сигналов со слотами |
| `usd_changed(text)` | Пересчёт рублей и евро при изменении значения в долларах |
| `rub_changed(text)` | Пересчёт долларов и евро при изменении значения в рублях |
| `eur_changed(text)` | Пересчёт долларов и рублей при изменении значения в евро |
| `on_rub_signal(value)` | Обработка сигнала об изменении суммы в рублях и вывод сообщения в консоль |
| `on_dolar_signal(value)` | Обработка сигнала об изменении суммы в евро и вывод сообщения в консоль |
| `on_usd_signal(value)` | Обработка сигнала об изменении суммы в долларах и вывод сообщения в консоль |
