# Лабораторная работа №1

# Задание

Разработать графическое приложение, содержащее окно, кнопку и надпись. При нажатии кнопки надпись должна изменяться на изображение.

# Описание программы

Программа разработана на языке **Python** с использованием библиотеки **PyQt5**.

Приложение представляет собой графическое окно с надписью и двумя кнопками:

- **«Кнопка 1: Заменить надпись»** — заменяет текстовую надпись на изображение;
- **«Кнопка 2: Изменить форму окна»** — изменяет форму окна и позволяет вернуть исходную форму;
- **«✕»** — закрывает приложение.

Окно приложения выполнено без стандартной рамки операционной системы и может перемещаться мышью.

## Используемые библиотеки

В программе используются следующие компоненты PyQt5:

```python
from PyQt5.QtWidgets import QApplication, QWidget, QVBoxLayout, QLabel, QPushButton, QHBoxLayout
from PyQt5.QtCore import Qt
from PyQt5.QtGui import QPixmap, QPainter, QColor
```

### Основные компоненты

- `QApplication` — запуск графического приложения;
- `QWidget` — основное окно программы;
- `QVBoxLayout` — вертикальная компоновка элементов;
- `QHBoxLayout` — горизонтальная компоновка;
- `QLabel` — отображение текста или изображения;
- `QPushButton` — кнопки управления;
- `QPixmap` — работа с изображениями;
- `QPainter` — отрисовка элементов;
- `QColor` — задание цветов.

## Основные элементы интерфейса

При запуске создаётся окно размером **400 × 350 пикселей**.

В окне расположены:

1. Кнопка закрытия окна.
2. Надпись `Надпись - текст`.
3. Кнопка `Кнопка 1: Заменить надпись`.
4. Кнопка `Кнопка 2: Изменить форму окна`.

### Работа первой кнопки

При нажатии на кнопку **«Кнопка 1: Заменить надпись»** вызывается метод:

```python
def change_label_to_image(self):
```

Метод загружает изображение из файла:

```python
pixmap = QPixmap("image.png")
```

Если файл изображения отсутствует, программа создаёт изображение размером `200 × 80` пикселей, добавляет на него надпись **«Надпись - изображение»** и сохраняет его в файл `image.png`.

После этого изображение масштабируется под размер `QLabel` и устанавливается вместо текста:

```python
self.label.setPixmap(pixmap)
self.label.setText("")
```

Первоначальная текстовая надпись заменяется изображением.

### Работа второй кнопки

Вторая кнопка предназначена для изменения формы окна.

При её нажатии вызывается:

```python
def change_window_shape(self):
```

Программа загружает изображение `shape.png`. Если файл отсутствует, создаётся прозрачное изображение с закруглённым прямоугольником.

После включения режима изменения формы:

```python
self.is_shape_mode = True
```

размер окна устанавливается в соответствии с размером изображения, а текст кнопки изменяется на:

```text
Кнопка 2: Вернуть форму окна
```

Повторное нажатие возвращает исходный размер окна и исходную форму.

### Отрисовка окна

Для отрисовки используется переопределённый метод:

```python
def paintEvent(self, event):
```

В обычном режиме окно отображается как прямоугольник с заданным цветом.

В режиме изменения формы используется изображение `shape.png`.

### Перемещение окна

Так как окно создаётся без стандартной рамки:

```python
self.setWindowFlag(Qt.FramelessWindowHint, True)
```

в программе реализовано перемещение окна мышью.

Для этого используются обработчики:

```python
mousePressEvent()
mouseMoveEvent()
mouseReleaseEvent()
```

При нажатии левой кнопкой мыши сохраняется положение курсора относительно окна, после чего окно можно перемещать.

## Структура программы

Основная логика приложения находится в классе:

```python
class LabWindow(QWidget):
```

В классе реализованы следующие методы:

| Метод | Назначение |
|---|---|
| `__init__()` | Создание и настройка окна и элементов интерфейса |
| `change_label_to_image()` | Замена текста на изображение |
| `change_window_shape()` | Изменение формы окна |
| `restore_original_shape()` | Восстановление исходной формы окна |
| `paintEvent()` | Отрисовка окна |
| `mousePressEvent()` | Обработка нажатия кнопки мыши |
| `mouseMoveEvent()` | Перемещение окна мышью |
| `mouseReleaseEvent()` | Завершение перемещения окна |

## Запуск программы

Программа запускается из блока:

```python
if __name__ == "__main__":
    app = QApplication(sys.argv)

    window = LabWindow()
    window.show()

    sys.exit(app.exec())
```

После создания объекта `QApplication` создаётся экземпляр `LabWindow`, окно отображается на экране, после чего запускается цикл обработки событий.
