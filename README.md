# Лабораторная работа №3

## Задание

Разработать графическое приложение на **Python** с использованием
библиотеки **PyQt5**, обеспечивающее подключение к базе данных SQLite,
отображение таблиц в графическом интерфейсе и выполнение SQL-запросов.

В соответствии с заданием приложение должно содержать меню для установки
и закрытия соединения с базой данных, набор функциональных кнопок и пять
вкладок `QTabWidget` для отображения результатов запросов. Дополнительно
реализовано модальное окно для ввода произвольного SQL-запроса.

## Описание программы

Программа состоит из двух частей:

1.  **Графическое приложение** - подключается к выбранной базе данных
    SQLite и отображает результаты SQL-запросов.
2.  **Скрипт создания базы данных** - создаёт файл `test.db` и
    заполняет его тестовыми данными.

Интерфейс приложения построен с помощью библиотеки **PyQt5**. Для работы
с базой данных используется стандартный модуль Python `sqlite3`.

В верхней части окна расположены:

## Работа с базой данных

### Установка соединения

В главном меню **«Файл»** находится команда `Set connection`. Она
вызывает метод:

``` python
def set_connection(self):
```

Для выбора базы данных используется диалог
`QFileDialog.getOpenFileName()`. Пользователь может выбрать файл с
расширением `.db`, `.sqlite` или `.sqlite3`.

После выбора файла создаётся соединение:

``` python
self.connection = sqlite3.connect(file_path)
```

Статус подключения отображается в верхней части окна. После успешного
подключения активируются функциональные кнопки и выпадающий список.

Затем автоматически выполняется запрос:

``` sql
SELECT * FROM sqlite_master
```

Результат выводится во вкладку `Tab1`, которая становится активной.

Для заполнения выпадающего списка выполняется запрос:

``` sql
SELECT name
FROM sqlite_master
WHERE type = 'table'
```

Таким образом, `QComboBox` содержит названия таблиц выбранной базы
данных.

### Закрытие соединения

Команда `Close connection` вызывает метод:

``` python
def close_connection(self):
```

Метод закрывает соединение с базой данных, очищает все пять вкладок,
сбрасывает выбранную таблицу и очищает выпадающий список. Функциональные
кнопки и список таблиц снова становятся недоступными.

## Работа функциональных кнопок

### Кнопка bt1 --- выборочный запрос

При нажатии на кнопку **`bt1: SELECT name`** вызывается:

``` python
def on_bt1_clicked(self):
```

Выполняется SQL-запрос:

``` sql
SELECT name FROM sqlite_master
```

Результат отображается во вкладке `Tab2`. После выполнения запроса
программа переключается на эту вкладку.

### Выбор таблицы в QComboBox

При изменении выбранного элемента выпадающего списка вызывается:

``` python
def on_column_changed(self, table_name):
```

В данном случае список содержит названия таблиц, а не отдельных колонок.
После выбора таблицы выполняется запрос:

``` sql
PRAGMA table_info([table_name])
```

Он возвращает сведения о структуре таблицы: порядковый номер поля, его
название, тип данных, признак `NOT NULL`, значение по умолчанию и
признак первичного ключа.

Результат выводится во вкладку `Tab3`.

### Кнопка bt2 --- вывод таблицы в Tab4

При нажатии на кнопку **`bt2: Таблица в Tab4`** вызывается:

``` python
def on_bt2_clicked(self):
```

Для выбранной таблицы выполняется запрос:

``` sql
SELECT * FROM [table_name]
```

В результате во вкладке `Tab4` отображаются все столбцы и записи
выбранной таблицы.

### Кнопка bt3 --- подсчёт записей в Tab5

При нажатии на кнопку **`bt3: Таблица в Tab5`** вызывается:

``` python
def on_bt3_clicked(self):
```

Выполняется запрос:

``` sql
SELECT COUNT(*) AS row_count FROM [table_name]
```

Результат --- количество записей в выбранной таблице --- отображается во
вкладке `Tab5`.

## Вывод результатов SQL-запросов

Для выполнения запроса и отображения результата в указанном элементе
`QTableWidget` используется общий метод:

``` python
def _execute_to_tab(self, query, table_widget):
```

Метод выполняет следующие действия:

1.  Очищает таблицу от предыдущего результата.
2.  Выполняет переданный SQL-запрос через
    `self.connection.execute(query)`.
3.  Получает названия столбцов из `cursor.description`.
4.  Получает все строки результата методом `fetchall()`.
5.  Настраивает количество строк и столбцов `QTableWidget`.
6.  Устанавливает заголовки столбцов.
7.  Заполняет ячейки полученными значениями.
8.  Устанавливает автоматический подбор ширины столбцов с помощью
    `QHeaderView.ResizeToContents`.

Если при выполнении запроса возникает ошибка SQLite, она отображается в
окне `QMessageBox`.

## Произвольный SQL-запрос (дополнительное задание)

В программе реализована возможность вводить собственные SQL-запросы
через отдельное модальное окно.

За его создание отвечает класс:

``` python
class QueryDialog(QDialog):
```

В окне расположены:

-   поле `QLineEdit` для ввода SQL-запроса;
-   кнопка `OK` для подтверждения;
-   кнопка `Cancel` для отмены.

Диалог является модальным:

``` python
self.setWindowModality(Qt.ApplicationModal)
```

После подтверждения введённый запрос обрабатывается методом:

``` python
def on_custom_query(self):
```

Результат выводится в текущую активную вкладку. Если пользователь
отменяет ввод, выполнение запроса не производится.
